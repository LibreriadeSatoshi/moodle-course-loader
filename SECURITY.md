# Security policy

## Supported versions

Security fixes are applied to the current default branch and, when releases are published, the latest release. Older versions may not receive updates.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue.

Email [security@libreriadesatoshi.com](mailto:security@libreriadesatoshi.com) directly. Include the repository name, affected version or commit, reproduction steps, potential impact, and any suggested remediation. Use sanitized examples only.

Do not include Moodle web service tokens, Google credentials or OAuth tokens, private spreadsheet contents, or real user or course data. If sensitive evidence is necessary, describe it first and wait for a secure exchange method.

We will acknowledge the report as soon as possible and coordinate disclosure after a fix is available.
